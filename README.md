# 📊 FinanceDynamics

Um sistema de **controle financeiro pessoal** desenvolvido com **C# e .NET 8**, com foco na aplicação de **boas práticas de engenharia de software** e **padrões de projeto** modernos. Idealizado como um repositório de **código aberto educacional**, o projeto serve como laboratório e referência prática de um sistema real com arquitetura bem definida e princípios sólidos.

---

## 🎯 Objetivos do Projeto

- Consolidar e demonstrar o uso real de técnicas modernas de desenvolvimento.
- Unir diversos conceitos fundamentais de arquitetura e boas práticas em um único projeto.
- Compartilhar um exemplo completo e funcional que possa servir de **material de estudo e inspiração**.

Este repositório é ideal para desenvolvedores que estudam ou querem aplicar:

- POO aplicada de forma madura
- Arquitetura limpa e modular
- Boas práticas e princípios de código limpo
- Design patterns e técnicas avançadas de codificação

## 🧠 Conceitos Aplicados

### Arquitetura

- 🧱 **Arquitetura Limpa** (Clean Architecture)
- 📦 Separação por camadas: Domain, Application, Infrastructure, Presentation
- 🧩 **Injeção de Dependência**
- 🏭 **Factory Method Pattern**
- 🎛️ **Facade Pattern**
- 🧬 **Data Mapper Pattern**

### Princípios e Boas Práticas

- 🧼 **Clean Code**
- 🔣 **SOLID**
- 🧱 **POO** (Programação Orientada a Objetos)
- ❌ **YAGNI** (You Ain’t Gonna Need It)
- ♻️ **DRY** (Don't Repeat Yourself)
- 📏 **Object Calisthenics**
- 🧱 **Guard Clauses**
- 📡 **Lei de Demeter**

### Testes

- ✅ **Testes Unitários** com MSTest
